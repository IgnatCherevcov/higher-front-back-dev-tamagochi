# Тамагочи

Консольная игра на Python с механикой ухода за питомцем и заработка монет. Реализована с использованием ООП и абстрактных интерфейсов, заданных шаблоном проекта.

## Запуск

Требуется Python 3.10 или новее. Для игры сторонние библиотеки не нужны.

```bash
python main.py
```

В меню доступны работа, покупка еды и лекарств, кормление, лечение, игра с питомцем и отдых. Для выхода используется команда `0`.

## Структура

```text
.
├── .github/workflows/default.yml
├── .gitignore
├── game/
│   ├── clicker.py
│   ├── constants.py
│   ├── exceptions.py
│   ├── game.py
│   ├── models.py
│   └── tamagochi.py
├── tests/test_game.py
├── main.py
└── README.md
```

В `game/` расположены классы игровой логики, модели, исключения и константы. `main.py` отвечает за консольное взаимодействие. Взаимодействие компонентов построено через абстрактные интерфейсы. Ввод и вывод не используются внутри классов игровой логики.

## Проверка

```bash
python -m unittest discover -s tests -v
python -m pytest tests -v
python -m ruff check . --select E4,E7,E9,F,I
python -m flake8 . --exclude=.git,.venv
```

`unittest` входит в стандартную библиотеку Python. Для запуска остальных команд нужны дополнительные инструменты, устанавливаемые отдельно: `pytest`, `ruff`, `flake8`.

## Игровые правила

- Питомец имеет четыре показателя: голод, усталость, здоровье и энергию.
- Работа приносит монеты; магазин продаёт еду и лекарства.
- Лекарства имеют ограниченное количество применений.
- Болезнь уменьшает эффективность отдыха и может снижать здоровье.
- При падении здоровья ниже нуля игра завершается.
- Успешные действия изменяют состояние питомца на один игровой ход.

Числовые параметры правил расположены в `game/constants.py`.
